## About the portfolio

This is the public showcase for **Manmeet Singh**, a front-end developer focused on smooth, motion-rich interfaces. The portfolio is designed as a kinetic editorial experience: typography, interaction, 3D motion, scrolling behavior, and interface feedback work together to make each section feel intentional rather than decorative.

The visual system is built around **Signal Cobalt**—warm paper surfaces, graphite depth, cobalt motion signals, and coral conversion moments. It reflects the kind of work presented here: expressive in motion, precise in structure, and responsive across screens.

---

## Signature experience

| Area | What it does |
| --- | --- |
| **Cinematic opening** | A minimal loading sequence uses the same 3D hero sculpture that later settles into the homepage before the interface reveals itself. |
| **Interactive 3D hero** | A real-time Three.js composition responds to cursor movement, click pulses, and the opening motion sequence. |
| **Engineered scrolling** | Lenis smooth scrolling, GSAP, and ScrollTrigger coordinate reveals, parallax, title movement, and section transitions. |
| **Custom cursor language** | Desktop interactions use contextual cursor labels and cobalt/coral particle trails. |
| **Responsive motion** | Desktop and mobile layouts preserve hierarchy while adapting navigation, typography, content rhythm, and interaction density. |
| **Accessible behavior** | Nonessential motion is reduced when a visitor enables `prefers-reduced-motion`. |
